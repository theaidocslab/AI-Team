# The Sovereign Stack™ — WordPress Plugin Suite

Real, working WordPress plugins built by Dr. Eric Townsend / The AI Docs Lab™.
"Sovereign" = no third-party dependencies, no external SaaS, data stays on the
client's own WordPress install.

## In this repo

- **`ai-crawler-pro-oborn.php`** — the exact, as-built plugin currently
  running on `oborn.com` (Oborn Transfer & Storage). Kept verbatim as a
  reference for what's actually live. Do not edit this file to "improve" it —
  if a change is needed for Oborn specifically, edit the copy running on
  their site and re-export it here.
- **`ai-crawler-pro-template.php`** — the same plugin with every
  client-specific default blanked out (business name, address, phone, domain
  lock, etc.), ready to duplicate for the next WordPress client. Fill in the
  entity fields and set the licensed domain from the plugin's admin page
  after activating on a new site.

### What AI Crawler Pro™ does

- Injects a `LocalBusiness` / `ProfessionalService` / `StorageFacility`
  JSON-LD entity block into `wp_head` (schema.org structured data, written
  for both search engines and AI assistants).
- Pings Bing instantly via the IndexNow protocol whenever a post or page is
  published.
- Generates an XML sitemap for Google Search Console submission.
- Domain-locks itself to one licensed domain (`aicrawler_licensed_domain`)
  so a copy can't just be handed off and reactivated somewhere else.
- Admin dashboard with an Entity Score health check (0–100) based on how
  many of the identity/authority fields are filled in.

## Delivery model

Two delivery paths depending on the client's existing site:

- **New coach/consultant with no existing site** — static HTML page (like
  `demo/live-demo-coach.html`) with hand-coded AEO/GEO equivalents: JSON-LD
  in `<head>`, `robots.txt`, `llms.txt`, `sitemap.xml`. No WordPress
  required.
- **Client already running WordPress** (like Oborn) — install the real
  Sovereign Stack™ plugin suite instead, starting with AI Crawler Pro™.
